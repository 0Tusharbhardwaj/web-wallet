## 🪙 Simple Ethereum Web Wallet

This is a **simple browser-based Ethereum wallet** built using **JavaScript and ethers.js**.  
It allows users to:

- ✅ Generate a **mnemonic phrase**
- ✅ Create **multiple Ethereum wallets** from that mnemonic
- ✅ View the **public address** of each wallet

No blockchain connection or server required — it works entirely in the browser!

---

### 📂 Features

- 🔐 **Mnemonic generation** (BIP-39 standard)
- 🔄 **HD Wallet Derivation** using BIP-44 path (`m/44'/60'/0'/0/n`)
- 👛 **Multiple wallet support** from a single mnemonic
- 💻 **Built with pure HTML, CSS & JavaScript**
- 📦 No installation needed — just open `index.html`

---

### 🚀 How to Use

1. Clone or download this repo
2. Open `index.html` in your browser
3. Click **"Generate Mnemonic"**
4. Click **"Add Wallet"** to derive new wallet addresses
5. Done! 🎉

---

### 🔧 Tech Stack

- [ethers.js](https://docs.ethers.org/v5/) via CDN
- HTML, CSS, JavaScript
